## Install:
Create a "mods" folder into your T3 root directory.
Paste the t3_reforged mod into your T3/mods folder.
Use the <a href="https://github.com/JacoboGutierrez/T3-ModTools" target="_blank" rel="noopener noreferrer">T3-ModTools</a> to build the mod into the Modded T3 executable.
Once you've done this, the mod has been patched into the game. You can play modded now; Use the T3_Modded.exe to run the game, otherwise mods won't load, and you'll play in vanilla.

## Important Notes:
1)The first time you run the game, after building the mod into the game first time, the game will crash and reopen. [this won't happen ever again] Unless you build or edit another mod that patches the game's engines.
2)If you have any of this mods in your mods folder, the mod won't work since the mod already includes those mods already built-in:
t3_fixed_weapons, t3_enhanced_sfx, t3_enhanced_t_units, t3_original_soundtracks
