## Installation
1. Create a `mods` folder in your T3 root directory.
2. Copy the `t3_reforged` mod into your `T3/mods` folder.
3. Use [T3-ModTools](https://github.com/JacoboGutierrez/T3-ModTools) (version 0.6.12 or later) to patch the mod into the game's executable.
4. Once the patching process is complete, the mod is ready to play. Launch the game using `T3_Modded.exe`. Otherwise, the mods won't load, and the game will run in vanilla mode.

## Important Notes
1. The first time you launch the game after patching the executable, it will crash and automatically restart. This is expected behavior and will only happen once, unless you install or modify another mod that patches the game's engine.

2. **Remove the following mods from your `mods` folder if you have them installed**, as they are already built into T3 Reforged and may cause conflicts:
   - `accurate_weapon_damage`
   - `t3_enhanced_sfx`
   - `t3_enhanced_t_units`
   - `t3_original_soundtracks`
3. Make sure you're using T3-ModTools version 0.6.12 or later to ensure compatibility with the mod.


## This Mod Features:

🔺 **Enhanced Skynet Models, Animations and Shading.**

🔺 **New Skynet Units:**
  - **T-900 Heavy Assault:**
    > A dual-wielding T-900 variant.

🔺 **New Weapons:**
  - **Dual Wield WM-20**
  - **WM-27 [Has a dual-wield variant]**
    > Deals more damage than the WM-20, has a lower fire rate, and does not include a grenade launcher.
  - **WM-32 [Has a dual-wield variant]**
    > Deals more damage than the WM-20 but less than the WM-27. Includes a plasma launcher.

🔺 **Enhanced & New Special Effects**
  > Changes to the HUD and additional effects, such as weapon muzzle flashes, projectile impacts, sounds, and more.

🔺 **Terminator 3 Original Movie Soundtrack**
